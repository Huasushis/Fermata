# 审题口味

Fermata 将基础构思的技术审查与选题偏好分开。每题每轮稳定抽取三个审美标签，重试不重新抽取；公开意见展示标签、第一印象和具体取舍。标签不与知识点目录混用，不要求一道题符合全部偏好。

技术结论可以是通过、需修改或不通过；个人口味是推荐或不推荐。不推荐可以产生不通过意见，即使题目技术上成立。推荐不能覆盖技术问题。提示词要求明确说明主观理由，不能编造错误或评价作者身份。Urmotiv 的最终状态仍由审核规则决定，不增加 Fermata 的权限，也不重审历史题。

验证：

- 类型检查与评分器、人格标签、机器人测试通过；覆盖同题同轮稳定、跨题变化、格式校验、技术拒绝不可被喜好覆盖，以及技术通过但因口味拒绝。
- 当前学校模型 `deepseek-flash`，审题 enabled/max、整理轮关闭思考；两个并发合成样本均完整返回，约 31 秒。简单加法被判断技术成立但不推荐；忽略负数的求和题解被判断有技术错误。均包含三项偏好、第一印象和理由。原始回答仅存私有区域。
- 完整测试：69 文件通过、8 个旧实验文件失败；1447 项通过、76 项失败。失败集合与已有基线一致，涉及旧实验路径、Git 校验及输出上限约定，不宣称全量测试通过。

修改前的固定七项完整基线见 [基础构思尺度报告](basic-proposal-review-20260921.md)。本次两个合成样本只验证功能和结构，不构成准确性提升证据。加入主观口味后，不能把“不推荐”直接解释为题目客观错误，也不能用这两个样本声称减少了偏差。
